Project 1: X Claude Code News Watch

Overview: A fully automated daily digest that researches X (Twitter) for the latest Claude Code news and delivers it straight to Evernote every morning.

Technology Stack: Node.js, xAI Grok API (live X search), Nodemailer/Gmail SMTP, Evernote email-import, macOS launchd

Details: Uses xAI's Grok live X-search to surface the 5 most notable Claude Code items each day — new feature announcements, tips, and notable community discussion — filtered for duplicates and formatted as a ready-to-read digest. Delivery runs through email rather than the (currently unavailable) Evernote developer API, and the whole pipeline is scheduled locally via launchd at zero hosting cost.

Project 2: RevOps AI Agent Portfolio

Overview: A runnable prototype of AI-assisted Revenue Operations — four auditable agents that take over a RevOps analyst's manual morning: CRM hygiene sweep, inbound lead triage, weekly pipeline review, and pre-call account research.

Technology Stack: Python (pandas), Anthropic Claude API, CSV mocks standing in for a Salesforce/HubSpot connector

Details: Built to be auditable rather than a black box — the lead-scoring model exposes its weights and prints the reasons behind every score, so the logic can be explained to a sales leader and tuned by a non-engineer. The AI briefing agent degrades gracefully without credentials, printing the prompt it would send alongside a sample brief, so the repository runs on a clean clone with no API key.

Project 3: AI Policy Research Assistant

Overview: A full-stack AI research assistant that drafts congressional briefings, policy memos, and structured AI risk assessments, backed by live web research and a 10-persona policy debate simulator.

Technology Stack: Python (FastAPI), Next.js (TypeScript), Anthropic Claude API, Tavily web search, ChromaDB (RAG), SQLite

Details: Implements several bounded "evaluator-optimizer" agent loops — the research pipeline grades its own evidence gaps and re-searches to fill them, the debate simulator detects genuine persona disagreement and runs a targeted extra round, and risk assessments re-verify and re-research any individually weak-grounded dimension. Each loop is cost-capped by design rather than open-ended.
